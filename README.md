# Courage Livingstone

Personal portfolio for Courage Livingstone — Product Designer + Frontend Developer.

Built with Next.js (App Router), TypeScript, Tailwind CSS v4, and Manrope.

## Stack

- Next.js 16
- React 19
- Tailwind CSS v4
- Manrope via `next/font`
- Sonner toasts
- React Hook Form + Zod

## Layout

All pages share `PageWrapper` (`.width-layout`): 1600px container with responsive padding, targeting ~1450px of content at `xl`.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

Update name, email, socials, and project copy in `src/lib/site.ts` and `src/lib/projects.ts`.
